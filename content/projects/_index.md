Heroic Lands is home to two Foundry VTT game systems and a growing collection of content modules and reference catalogs. Each section below has its own landing page.

# [Song of Heroic Lands](/projects/song-of-heroic-lands/)

SoHL — the HârnMaster-compatible Foundry VTT system designed to run the world of Thalorna. User Guide, Rules, Quickstart, and Character Creation.

# [HârnMaster 3](/projects/harnmaster-3/)

The mature HârnMaster 3 Foundry VTT system and the HârnMaster-specific modules that extend it.

# [Modules](/projects/foundry-vtt-modules/)

System-agnostic Foundry VTT content modules — locations, adventures, and campaign material usable with any game system. Plus install instructions for Foundry.

Reference catalogs for SoHL and HârnMaster — domains, skills, traits, abilities, armor, weapons, and other building-block items.
