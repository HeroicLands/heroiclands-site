**Song of Heroic Lands** (SoHL) is a classless, skill-based Foundry VTT system, compatible with the [HârnMaster](https://www.kelestia.com/harnmaster) ruleset and built to run the world of Thalorna.

It keeps the books so you can make the calls. SoHL tracks the wounds, the healing, the calendar, and the stack of modifiers behind every roll, and every number on a sheet shows where it came from. What it will not do is play for you: something happens to a character only when that character's player asks for it or accepts it.

# Get it

SoHL is released and installable in Foundry VTT v14. [**/sohl/**](/sohl/) carries the manifest URL and the install steps, alongside what is in the current release.

The system is in active development, so expect change between releases.
